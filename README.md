## Usage

Copy the markdown below and paste it in your GitHub README.

```md
[![Readme Quotes](https://github-readme-quotes-torvalds.vercel.app/api?type=horizontal&theme=tokyonight)](https://github.com/CarlJlin/github-readme-quotes-torvalds)
```

### Options

| Option          | Default  | Description                                      |
| --------------- | -------- | ------------------------------------------------ |
| type            | vertical | `horizontal`, `vertical`                         |
| theme           | light    | [Available themes](#themes)                      |
| border          | false    | `true`, `false`                                  |
| quote           | -        | Custom quote (URL encoded)                       |
| author          | -        | Custom author name                               |
| quoteColor      | -        | Quote text color (hex without `#`)               |
| authorColor     | -        | Author text color (hex without `#`)              |
| backgroundColor | -        | Background color (hex without `#`)               |
| symbolColor     | -        | Quote symbol color (hex without `#`)             |
